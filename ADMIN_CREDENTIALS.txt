================================================================================

TROUBLESHOOTING:

1. Admin account not created?
   → Run: npm run seed

2. Cannot login?
   → Check MongoDB is running
   → Verify backend server is running (http://localhost:5000)
   → Check MONGODB_URI in .env

3. Token expired?
   → Token expires in 7 days
   → Login again to get new token

4. Forgotten password?
   → Delete admin account and re-run: npm run seed
   → This creates a fresh admin account with default password
