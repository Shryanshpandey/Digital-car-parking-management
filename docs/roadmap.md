# Theme and Design System

## 1. Design Objective
The Digital Car Parking Management UI should feel professional, trustworthy, and efficient. The design should help users operate quickly while keeping information easy to scan and understand.

## 2. Visual Style
The product uses a clean modern dashboard aesthetic with:
- strong blue accents for trust and stability
- green for available or successful actions
- amber for warnings or reservations
- red for errors or critical alerts
- neutral cards and surfaces for readability

## 3. Color Palette
```css
--primary: #1E3A8A;
--primary-dark: #10285C;
--secondary: #10B981;
--accent: #F59E0B;
--danger: #EF4444;
--background: #F8FAFC;
--surface: #FFFFFF;
--text: #0F172A;
--muted: #64748B;
--border: #E2E8F0;
```

## 4. Typography
- Heading Font: Inter or Poppins
- Body Font: Inter
- Font Weights: 400, 500, 600, 700

## 5. Layout System
- Sidebar navigation for app sections
- Top bar with search, alerts, and profile actions
- Grid-based KPI cards for key metrics
- Tables for vehicle and billing records
- Forms with clearly labeled fields and actions

## 6. Component Standards

### Buttons
- Primary: blue filled background, white label
- Secondary: white with blue border
- Danger: red background with white label
- Hover states with subtle elevation

### Cards
- White surface
- Rounded corners
- Light border and soft shadow
- Small padding consistent across modules

### Status Badges
- Available: green
- Occupied: blue
- Reserved: amber
- Full: red

### Inputs
- Light border
- Medium radius
- Clear focus ring
- Consistent spacing

## 7. Accessibility
- Text contrast suitable for readability
- Buttons and actions keyboard accessible
- Clear focus states
- Scannable labels and error states

## 8. Responsive Behavior
- Desktop: full dashboard with sidebar and wide tables
- Tablet: simplified layout with reduced spacing
- Mobile: stacked cards and condensed navigation

## 9. UI Example Sections
- Dashboard overview
- Parking slot grid
- Vehicle check-in form
- Vehicle checkout summary
- Payment and billing panel
- Reports and analytics charts

---

This theme system is intended to be used consistently across all dashboard screens and modules.
