# Contributing Guide

Thank you for contributing to the Digital Car Parking Management project.

## How to contribute
1. Fork the repository.
2. Create a feature branch.
3. Make focused changes.
4. Validate locally using the project scripts.
5. Open a pull request with a clear description.

## Development Process
- Keep components modular and reusable.
- Follow existing naming conventions.
- Update relevant documentation when changing features or architecture.
- Ensure the UI remains accessible and responsive.

## Coding Standards
- Use clear, readable variable names.
- Prefer small reusable components.
- Keep styling consistent with the design system.
- Add comments only where necessary.

## Pull Request Checklist
- The change is scoped and easy to review.
- Documentation is updated where required.
- Functional and UI changes are tested manually.
- No unrelated files are included.

## Commit Message Guidance
Use concise and descriptive messages such as:
- `feat: add parking dashboard overview`
- `fix: correct slot availability logic`
- `docs: update architecture document`

---

Contributions help improve the quality and usability of the parking management platform.
